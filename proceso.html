DEL PROYECTO LOCAL A LA WEB

Cómo construimos Preguntas Soy Luna

Un recorrido breve por las decisiones, herramientas y tecnologías que usamos para crear, probar, versionar y publicar la trivia.

La idea centralCrearProbarGuardarPublicarVersionar
01 / IDEA

Definimos el juego

Convertimos el pedido en reglas concretas: preguntas de opción múltiple, una por vez, contador, configuración, límite de tiempo, tres errores y resumen final.

02 / LOCAL

Trabajamos en VS Code

Visual Studio Code es el editor donde vemos y modificamos los archivos del proyecto. La carpeta local fue nuestro espacio de trabajo antes de subir cualquier cosa a internet.

03 / CODEX

Construimos con Codex

Codex funcionó como asistente de programación: leyó el contexto, propuso código, creó archivos, corrigió detalles y ejecutó comprobaciones. La decisión final y las pruebas quedaron bajo nuestro control.

04 / CÓDIGO

Separamos responsabilidades

HTML organizó las pantallas y controles. CSS definió la estética “Argentina”: colores celeste, fucsia y amarillo, diseño responsive y tarjetas. JavaScript manejó preguntas, tiempo, respuestas, resultados y ranking.

05 / PRUEBAS

Probamos como usuarios

Abrimos la página en el navegador, iniciamos partidas, verificamos las tres opciones, el contador, las respuestas correctas e incorrectas y el cierre automático al agotarse el tiempo.

06 / GIT

Guardamos la historia

Git registró los cambios en commits. La rama main conservó la versión estable y creamos version-2 para trabajar mejoras sin perder la versión anterior. La etiqueta v1.0 identifica ese punto.

07 / GITHUB

Subimos el repositorio

GitHub alojó el proyecto en línea. Desde VS Code ejecutamos el envío de archivos con Git y comprobamos que el repositorio remoto recibiera el código.

08 / PAGES

Lo publicamos

GitHub Pages convirtió la rama main en un sitio web. Las carpetas permiten que cada versión tenga una URL propia, sin necesitar otro repositorio.

HERRAMIENTAS DEL PROYECTO

Qué hace cada tecnología

HTML

Estructura semántica: títulos, formularios, botones, preguntas y referencias.

CSS

Colores, tipografías, espaciado, responsive y estados visuales.

JavaScript

Lógica interactiva, selección aleatoria, cronómetro, reglas y resultados.

Git

Historial local de cambios, commits, ramas y etiquetas.

GitHub

Repositorio remoto, colaboración y almacenamiento del código.
